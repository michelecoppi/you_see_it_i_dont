# Marketplace icons

These five 512 × 512 PNG files are ready to upload in Roblox Creator Hub for
`YOU SEE IT, I DON'T`. Roblox displays shop icons inside a circular crop, so
the main subject stays near the center. Keep the text names and prices in the
Creator Hub fields rather than on the images.

## Generation prompt set

Generated with the built-in `image_gen` tool using the project's sci-fi art
direction (`docs/images/art_direction.png`, `docs/images/cosmetic_drone.png`)
as visual guidance. Each icon requested a standalone square stylized 3D game
item render on a near-black navy background with no text, logo, or watermark:

- **Void Drone:** hovering black segmented spherical drone, violet eye and
  gravitational ring.
- **Prismatic Vision:** futuristic visor with faceted cyan-to-violet lens and
  holographic scanning rays.
- **500 Shards:** small cyan crystal cluster above a dark steel pedestal.
- **1,250 Shards:** fuller cyan crystal cluster with a violet central shard.
- **3,000 Shards:** abundant cyan-violet crystal crown with radiant central
  crystal and two containment rings.

The generated originals were downsampled to 512 × 512 PNG for Creator Hub.
